SD Card Management
Format the SD card to recover from file system corruption or to apply new logging parameters. The format request will be queued and executed on the next system restart.
Warning: This will erase all data on the SD card and reset the log ring.
Note: CAN logs are stored using file rotation.
Tip: If the SD card becomes unresponsive during long runs, a full reformat on a computer usually fixes it. Do this before an important logging session.
